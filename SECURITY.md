# Security & Privacy Policy

## 🛡️ Privacy Commitment

**Hesaplı İzin** is built as an **offline-first, client-side Progressive Web App**.

- **No Remote Telemetry or Tracking**: We do not collect, send, or store your annual leave data, company preferences, budget inputs, or custom holidays on any server.
- **Local Storage Only**: All user settings and saved leave plans are stored exclusively in your local browser storage (`localStorage`).
- **No Third-Party Analytics**: No external scripts or tracking cookies are included.

---

## 🔍 Reporting Security Vulnerabilities

We take security seriously. If you discover a security vulnerability within this project, please report it privately to the maintainers rather than opening a public issue.

### How to Report

Please send an email to the project maintainers or report via GitHub Security Advisories if enabled. Include:
1. Description of the vulnerability or risk.
2. Steps or proof-of-concept to reproduce the issue.
3. Affected components or files.

### Response Expectations

- **Acknowledgment**: Within 48 hours.
- **Status Update**: Within 7 business days.
- **Fix & Patch**: Released promptly after confirmation.

Thank you for keeping **Hesaplı İzin** safe and private for everyone!
